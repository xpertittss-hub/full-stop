# FULL STOP Website Prototype

A React + Vite one-page local business website for FULL STOP, Bhiwandi.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Notes
- Logo is in `src/logo.jpg`.
- Location: 19.3008207, 73.0560904.
- Phone: 9766592316.
- Website is structured for local SEO with LocalBusiness JSON-LD.
- Replace the canonical URL in `index.html` with the final domain before deployment.
